## 🚀 Featured Projects

### ⚙️ [SuperAnandLang — Experimental Programming Language](https://github.com/SuperAnand67/SuperAnandLang)

An experimental programming language built from scratch using **C, Flex, and Bison** to explore lexical analysis, parsing, symbol tables, and language design.

**Highlights**

- Custom lexical analyzer using Flex.
- Grammar and parser implementation using Bison.
- Integer variable declarations and reassignment.
- Two-dimensional symbol table for variable storage and lookup.
- Arithmetic expression evaluation with operator precedence.
- String concatenation using the `+` operator.
- Postfix increment and decrement operators (`++`, `--`).
- String escape sequence handling.
- Custom comment syntax and error handling.
- Dedicated VS Code TextMate grammar for syntax highlighting.

**Technologies:** C · Flex · Bison · GCC · GNU Make · TextMate Grammar

---

### 📖 [Japanese Dictionary — JavaFX](https://github.com/SuperAnand67/Japanese-Dictionary-JavaFX)

An offline-first Japanese Kanji dictionary and learning application built using Java, JavaFX, and SQLite.

**Highlights**

- MVC architecture and modular project structure.
- SQLite-based local database integration.
- Kanji lookup and English meaning search.
- Bookmark management and persistent local data.
- Dark and light themes using AtlantaFX.
- Maven-based dependency and build management.
- Cross-platform Windows and Linux support.
- Native `.msi` and `.deb` application packaging.

**Technologies:** Java 25 · JavaFX 25 · SQLite · JDBC · Maven · AtlantaFX

---

### 🌐 [NetChat — TCP/UDP Chat Application](https://github.com/SuperAnand67/tcp-udp-chat-app)

A command-line client-server chat application exploring communication using TCP and UDP socket programming in Java.

**Highlights**

- TCP and UDP communication.
- Client-server architecture.
- Multithreaded message handling.
- Message and byte statistics.
- Application-level network diagnostics.
- RTT measurements and response-rate calculations.
- UDP acknowledgement-based diagnostics.
- Configurable simulated packet loss.

**Technologies:** Java · Socket Programming · TCP · UDP · Multithreading · Maven
