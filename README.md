**Highlights**

- SQLite database integration.

- Maven-based dependency and build management.
- Cross-platform support for Windows and Linux.
- Native application packaging.

**Technologies:** Java · JavaFX · SQLite · JDBC · Maven

### 🌐 [NetChat — TCP/UDP Chat Application](https://github.com/SuperAnand67/NetChat)

A computer networking mini-project exploring communication between applications using TCP and UDP sockets.

**Highlights**

- TCP and UDP communication.
- Client-server architecture.
- Sequence number handling.
- Simulated packet loss.
- Network statistics and diagnostics.

**Technologies:** Java · Socket Programming · TCP · UDP

---

### ⚙️ [SuperAnandLang — Experimental Programming Language](https://github.com/SuperAnand67/SuperAnandLang)

An experimental programming language developed using C, Flex, and Bison to explore compiler construction.

**Highlights**

- Custom lexical analyzer using Flex.
- Grammar and parser implementation using Bison.
- Arithmetic expression evaluation.
- Operator precedence and parentheses.
- String handling and escape sequences.
- Custom comment syntax.
- Automated compilation using GNU Make.

**Technologies:** C · Flex · Bison · GCC · Make
